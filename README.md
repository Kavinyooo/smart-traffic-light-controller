# 🚦 Smart Traffic Light Controller

An FSM-based Smart Traffic Light Controller designed using **Verilog HDL**. The controller manages normal traffic flow while supporting emergency vehicle priority and pedestrian crossings. The design was simulated and verified using **Xilinx ISE**.

---

## Features

- Finite State Machine (FSM) architecture
- Normal traffic signal sequencing
- Emergency vehicle priority handling
- Pedestrian crossing support
- Verilog testbench included
- Simulation waveform verification

---

## Technologies

- Verilog HDL
- Xilinx ISE
